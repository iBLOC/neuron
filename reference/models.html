This page is generated from the authoritative catalog in src/capabilities/catalog.rs (default_capabilities()). Every entry is what /v1/models advertises with is_default / engine metadata. For measured speed and memory numbers see /reference/benchmarks.

Platform default ​

minicpm5-1b (OpenBMB, Apache-2.0) — 1B LlamaForCausalLM, 131K context, hybrid <think> reasoning, runs on candle (CPU f16 or CUDA bf16). Registered under the candle engine; tag is_default: true.

Engines are the engine_impl strings used in config registrations and /v1/models; per-request inference executors (e.g. tract vs ort inside the OCR engine) are noted separately. All entries require their feature flag (see /concepts/feature-flags).

The engine's session executor is pluggable: tract (pure Rust, default) or ort (onnxruntime, ~10× faster). Optional add-on models in the same directory: rec-<pack>/ language packs (109 scripts), layout.onnx (PP-DocLayoutV3, ~130 MB), table.onnx (SLANeXt, ~368 MB). See /howto/ocr.

Catalog vs runtimes

Decision and Chronos2 have full runtime implementations and HTTP endpoints but ship no default catalog entry, because nothing downloadable loads as-is (Laya needs its export/prep pipeline; Chronos2 needs a checkpoint). Register them explicitly via env vars — see /reference/env-vars.
