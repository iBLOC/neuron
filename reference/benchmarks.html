Benchmarks ​

Measured performance and memory numbers for neuron's inference paths. Within each capability, all rows come from the same host and same workload so the models are directly comparable against each other. Rows marked with a footnote come from an earlier run on the same host class — compare within a table, not across tables. Every table states machine, revision and workload; reproduction commands are at the bottom.

Host for all tables below: Windows 11, 12 cores, 16 GB RAM, RTX 3090 (CUDA rows need --features cuda, not part of default builds).

¹ measured 2026-09-27 (rev 732f5c8, 12-token decode, 64/256-word prompts); other rows measured 2026-10-11 (rev 952a251, 32-token decode). Same host, same methodology (client-side timing, warmup discarded, unique prompt heads) — treat the minicpm5 rows as directionally comparable, the qwen rows as the current-code baseline.

Reading the table: decode rate is the steady-state generation speed; CUDA bf16 needs --features cuda (not in default builds). candle's CPU backend has no bf16 matmul and — as of the current build — rejects f16 logits on the CPU path, so CPU rows are f32 (highest memory). Larger catalog models (llama-3-8b, mistral-7b, chatglm-3-6b, Gemma tier) can be measured with the same harness; their numbers are not yet published.

Reproducing ​

bash
# LLM TTFT / decode tok/s / peak RSS vs vLLM / ollama / llama.cpp
# (starts installed servers; report -> target/llm-speed-compare.md)
./scripts/run-llm-speed-compare.sh

# Per-capability × per-engine matrix against a running neuron_server :18083
# (report -> target/model-matrix.md)
cargo bench --bench model_matrix --features "candle,tract,sherpa,voxcpm"

# ASR tract-vs-sherpa (report -> target/asr-speed-compare.md)
cargo bench --bench asr_speed --features tract,sherpa

# Allocation / pooling microbenchmarks
cargo bench --bench mobile_bench
cargo bench --bench perf -- --quick

Methodology notes (prompt-nonce anti-caching, client-side timing, warmup discard, greedy decode) live in each generated report's header — see benches/llm_speed.rs and AGENTS.md for the full contract.
