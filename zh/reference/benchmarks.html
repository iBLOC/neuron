基准测试 ​

neuron 各推理路径的实测性能与内存数据。同一能力内的所有行来自同一台 主机、同一负载,模型之间可直接横向对比;带脚注的行来自较早一轮同级别 主机实测——表内可比,跨表不可比。每张表都标注机器、代码版本与工作负载, 复现命令见文末。

以下所有表的主机:Windows 11,12 核,16 GB 内存,RTX 3090(CUDA 行需要 --features cuda,不在默认构建内)。

解读:解码速率是稳态生成速度;CUDA bf16 需要 --features cuda(不在 默认构建内)。candle 的 CPU 后端无 bf16 matmul,且当前构建的 CPU 路径 拒绝 f16 logits,因此 CPU 行均为 f32(内存最高)。目录中更大的模型 (llama-3-8b、mistral-7b、chatglm-3-6b、Gemma 系)可用同一工具实测, 数据暂未发布。

复现方法 ​

bash
# LLM TTFT / 解码 tok/s / 峰值 RSS,对比 vLLM / ollama / llama.cpp
# (自动启动已安装的服务;报告 -> target/llm-speed-compare.md)
./scripts/run-llm-speed-compare.sh

# 能力 × 引擎矩阵,对运行中的 neuron_server :18083
# (报告 -> target/model-matrix.md)
cargo bench --bench model_matrix --features "candle,tract,sherpa,voxcpm"

# ASR tract 与 sherpa 对比(报告 -> target/asr-speed-compare.md)
cargo bench --bench asr_speed --features tract,sherpa

# 内存分配 / 池化微基准
cargo bench --bench mobile_bench
cargo bench --bench perf -- --quick

方法论说明(提示词防缓存、客户端计时、预热丢弃、贪心解码)在各报告 头部与 benches/llm_speed.rs、AGENTS.md 中有完整约定。
